# 电视剧订阅来源与调度

当前实现支持两种互斥来源：

- `source=tg`：直接检索指定公开频道的消息预览，支持频道链接或用户名、关键词搜索和有界历史翻页。不调用 PanSou，也不在失败或无结果时回退到 PanSou。私有频道仍需后续的授权账号接入。
- `source=pansou`：使用全局 PanSou 搜索配置，不调用独立 TG 频道读取器。全局 PanSou 自身包含哪些插件/公开频道，仍由全局设置控制；这不属于直接频道订阅。

选择 TG 时至少填写一个公开频道，例如 `https://t.me/vip115hot`。选择 PanSou 时清除订阅专用频道，避免隐藏的残留配置改变实际来源。切换来源会清除原来源的候选并重新调度；原有公共下载任务不受影响。

旧订阅兼容：没有 source 字段但填写过频道的订阅视为直接 TG；其余视为 PanSou。

## 按集数安排资源检索

1. 从 TMDB 读取本季各集播出日期，按北京时间比较。
2. 尚未播出且没有到期缺集时，不请求资源来源；下次资源检查时间设置为最早的未找到剧集播出日。
3. 到期未找到，24 小时后补查；如果另一集更早播出，则以那个播出日为准。
4. 找到到期剧集后，立即重新计算下一集日期，不继续每天搜已经找到的集。
5. 未知日期的未找到剧集每天补查；所有已知剧集都有资源后停止资源检索，继续低频读取 TMDB，以便发现新增或调整的排期。

例：E01 周一播出，周一/二/三未找到，分别安排次日；周四找到后，等 E02 下周一播出再查。如果周四仍有其他已经到期的缺集，则继续每日补查那些缺集。

资源检查截止时间、元数据检查时间、候选与订阅来源持久化保存，重启不会重置为每分钟搜索。检查超时也会记录错误并遵循下次补查时间；主动取消请求不回写未完成结果。

## 频道解析与合集

频道读取器固定访问 Telegram 公开预览域名，不跟随重定向到其他网站；用户输入只允许公开频道用户名，不能作为任意抓取 URL。每个频道最多读取 5 页关键词匹配消息，正文限制 2 MiB，HTTP 请求有超时。该上限是一次任务的工作量限制，不代表频道只支持 20 条历史。

读取正文和隐藏超链接，提取合法 115 分享/提取码与 BT v1 磁力；其他网盘不会进入当前公共下载。多作品混合帖子在无法可靠划分时跳过，避免串配。

`S01E02`、`第2集` 等保持单集语义；`更05集`、`全8集` 另存为合集进度，不能当作单个 E05/E08 文件。调度把它作为频道声明的可用范围，日历区分标记；不是文件完整性或下载完成证明。下载仍走公共选文件/转存流程，合集不预填单集文件映射。
