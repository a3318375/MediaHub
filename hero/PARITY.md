# shadcn → HeroUI 交互对照

以当前 `web/src` 中实际挂载的页面为准。旧版仍保留但没有菜单入口的组件，不代表需要在 HeroUI 中重新增加独立功能入口。

| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `web/src/layouts/media-shell/navigation-data.ts`                           | 8 个导航入口、顺序和分组一致；默认 Emby 看板；移除总览、独立电视剧订阅、下载记录和影视整理菜单。                   |
| `web/src/App.tsx`                                                          | 旧整理、下载地址转到设置；兼容原版探索、榜单、动漫、日历、日志地址。                                               |
| `web/src/components/settings-page.tsx`                                     | 原版 7 个设置分类；TMDB、Emby、115 合为基础配置，一次保存；资源搜索保留 TG 频道、插件、网盘类型、检测 4 个子分类。 |
| `web/src/components/secret-setting.tsx`                                    | 掩码、显示全文、隐藏、修改、取消修改；115 Cookie 可展开为多行；留空保留现有值。                                    |

## 验证范围

- 自动对照原版导航与设置分类，验证删除入口和旧地址兼容。
- 验证原版历史兼容、不同搜索类型共存、关键词去重。
- 浏览器验证海报直接搜索、带数量的网盘分类、返回探索、详情页面、键盘菜单搜索、设置 7 分类及下载记录折叠入口。
- 390px 手机宽度检查设置页、菜单和海报操作；桌面检查资源搜索。
- API 契约与既有后端联调结果见 README。浏览器外观验收使用独立端口上的演示数据；不据此声称真实 115 文件操作或已有 Emby 实例验证通过。

HeroUI 组件的视觉样式与 shadcn 保持各自风格。这份对照记录的是已经核对的结构与行为，不代表所有页面逐像素一致。
