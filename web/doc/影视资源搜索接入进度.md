# 影视资源搜索接入进度

**更新日期：** 2026-10-13  
**当前阶段：** 已完成 PanSou 进程内集成、正式资源搜索页面、设置接入及启动初始化，代码已提交并推送；进入联调验收阶段。

## 目标与实现方式

- PanSou 编译进媒体中心 API 进程，共用系统鉴权和数据目录，无需额外部署 PanSou Docker 服务。
- 上游通过 Git submodule 固定版本；保留薄适配层，复用 PanSou 搜索、异步补齐、缓存和链接检测，便于后续更新。
- 搜索行为参考 [PanSou Web 开源前端](https://github.com/fish2018/pansou-web)，保留媒体中心现有页面设计。

## 已完成

### 搜索入口和页面

- 影视探索卡片、作品详情页及手动搜索共用资源搜索链路；保留搜索历史、最近结果及从探索页返回的入口。
- 结果按网盘类型分组，显示数量、来源、链接和提取码，支持复制。
- 每次搜索读取最新服务端配置，实际使用已保存的频道、插件和网盘类型。
- 按 PanSou Web 流程执行频道首轮、插件预热及后续 2/3/3 秒间隔收集；普通搜索使用缓存。
- 修复默认频道遗漏、过低并发限制、请求扩展参数差异、零时间展示及重复轮询占满异步槽的问题。
- 相同条件的并发搜索合并执行；取消旧搜索可立即停止等待，后台补齐仍有明确时限。

### 设置与换电脑初始化

- 现有资源搜索设置支持频道、插件、网盘类型及自动检测；补齐自定义频道添加和删除。
- 可选插件来自实际初始化的管理器，保存后的选择真正生效；明确的空列表和关闭状态不会被重置。
- 后端启动自动补齐缺失配置，迁移旧版未初始化占位值；默认清单从固定 PanSou 版本生成，无需先打开设置页。
- 已用全新数据目录验证初始化：111 个频道、71 个启用插件、14 个网盘类型，配置版本为 1。数量可随上游版本和部署环境变化。
- Windows 直接启动后端会读取已启用的系统代理；显式代理环境变量优先。开发和更新脚本同样初始化当前进程的代理环境。
- 默认配置随代码恢复；个性化配置和加密凭证跨电脑迁移仍需同步 `data/`，数据库与 `master.key` 必须一起保留，不提交到 Git。

### 链接检测、缓存和更新

- 自动检测开关已接入 PanSou 检测服务，仅检测当前可见链接，每批最多 6 条，状态不改变搜索结果。
- 搜索、元数据及检测接口均使用系统鉴权；检测请求限制分享域名，结果链接拒绝可执行协议。
- 检测缓存位于数据目录；不同 PanSou 版本和启用插件集合使用独立搜索缓存命名空间。
- 更新脚本自动生成插件注册和默认配置，准备必要嵌入补丁，验证测试、静态检查及单后端二进制构建。
- 已实测更新失败回滚：原子模块版本、嵌入修改、模块文件和生成文件逐字节恢复。
